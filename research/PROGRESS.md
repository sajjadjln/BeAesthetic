## Key decisions about the research itself
- BeAesthetic has one user and no business goal, so phases 0, 3, 4, 6, 7 get the most weight; marketing (5) is short and conditional on a Bazaar release.
- "Retention" = the user still doing the program in weeks 6–23. Experiments are n = 1 self-experiments (ABA / alternating weeks), not A/B tests.
- No changes to `docs/` or app code. Recommendations are proposals for the user to accept or reject.
