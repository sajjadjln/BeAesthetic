The wizard's + button: options

Four ideas for the elderly wizard's new-task button, next to the crystal orb he has now. All are drawn smooth in his silver, like the orb. Tap each button to see its press. Each one also moves a little while idle.

Reading as "add": the hat, the book and the potion carry a dark or glowing +. The sparkle is itself a + shape, so it needs no extra mark.
Idle motion: stars twinkle, the hat tip sways, the rune floats or bubbles rise. All of it stops when the phone's animations are off.
Color: everything is his silver except the potion, which adds a pale blue liquid. That would be the only second color on any character's button.
Build cost: each is a few Compose paths, like the orb today. No bitmap.
