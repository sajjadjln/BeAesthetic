First launch: pick your character (D186)The first screen after install. Each character brings its own theme: the knight is cyan and night blue, the vampire red, the goth woman purple, the wizard silver gray. The whole screen (sky, glow, dialog box, button) shifts when you pick. The four sit in a row of pixel cards; the knight is picked by default. Tap a card: the big portrait swaps in with its calm face, its name tag pops, and it introduces itself in the dialog box. Tap the picked card again (or the box) and it smiles (its happy mood) with a second line. The button names who you take: «با شوالیه بریم». No skip: the default is already a choice. Then the next step slides in: «امروزت چه شکلی باشه؟», the same character (happy) explains each choice. Two pixel cards with a sketch of each Today layout: «فهرست» (picked by default) and «بخش‌های روز». It can be changed later in Settings (D188). «شروع کنیم» goes on with onboarding.
