A preview of “Simple”, the look for people who don’t want a companion. Same colors, same rules, same screens; the character and the pixel style go away. Tap tasks to tick them, try both Today layouts, open + and Settings.

What changes in Simple

  • No character anywhere: no portrait, no dialog box, no lines, no hop. The «الان» card already says what to do now, so the character's job is covered.
  • Today’s top becomes a plain count, «۲ از ۹», a thin bar of one segment per task, and one quiet line. Done is still green; nothing is red.
  • Flat, not pixel: rounded corners, one grouped list per part of the day, line icons. No scanlines, embers or stepped corners.
  • The color stays a choice: the same four palettes, named by color (فیروزه‌ای, قرمز, بنفش, نقره‌ای) instead of by character.
  • 100% day: the bar flashes once and the line says the day is done. No hop.
  • New task sheet: a title in place of the character; everything else is the same, with «ذخیره» pinned.
  • Splash is unchanged; it is the logo, not a character.

Where the choice lives

  • Onboarding, step 1: «با همراه» or «ساده». Picking Simple skips the character step and shows the 4 colors instead.
  • Settings, «ظاهر»: the same switch, any time. Switching back to «با همراه» shows the four cards again.

For the code

  • One setting, companion: Character?; null means Simple. The palette moves to its own accent setting, so the theme no longer comes from the character.
  • Two style sets behind one theme API (shapes, the check, the progress): pixel for companions, flat for Simple. Screens ask the theme instead of hard-coding pixel shapes.
