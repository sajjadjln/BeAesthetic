# Character texts

Every line the companions say, from `app/src/main/res/values/strings.xml` (English) and `values-fa/strings.xml` (Persian). Generated from the strings (D216); the strings files win if they differ.

Today pools: **calm** (nothing done yet), **busy** (some done), **happy** (all done), **night**. Tapping the dialog box shows the next item.
